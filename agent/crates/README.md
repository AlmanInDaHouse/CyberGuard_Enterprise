# Agent crates

Workspace members for the CyberGuard agent. Each subdirectory is an independent Cargo crate.

| Crate | Purpose |
|---|---|
| [`cg-agent-core/`](cg-agent-core/) | Cross-platform runtime. |
| [`cg-agent-windows/`](cg-agent-windows/) | Windows platform crate. |
| [`cg-agent-linux/`](cg-agent-linux/) | Linux platform crate. |
| [`cg-agent-cli/`](cg-agent-cli/) | CLI / installer crate. |
