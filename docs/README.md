# Documentation

This directory hosts all project documentation.

## Language policy

All in-repo artifacts — specifications, architecture decision records, code comments, commit messages, READMEs — are written in **English**. Chat and product discussions between the team can happen in any language; the documentation that lives in the repository does not.

This convention follows the MADR ADR format and aligns with OCSF, MITRE and other upstream references the project consumes.

## Layout

| Subfolder | Purpose |
|---|---|
| [`adr/`](adr/) | Architecture Decision Records (MADR format). |
| [`architecture/`](architecture/) | High-level diagrams, data flow, component interaction. |
| [`security/`](security/) | Threat model, secure coding guidelines, privacy considerations. |
| [`specs/`](specs/) | Functional + technical specifications (SPEC-XXX). |
| [`product/`](product/) | Product vision, MVP definition, roadmap. |
| [`operations/`](operations/) | Runbook, observability, incident response for operators. |
